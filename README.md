rewindOS is an early-stage operating system project. Its security has not been independently audited or thoroughly tested.

Known security limitations

- No mature security architecture.
- No complete user permission system.
- No fully developed application sandboxing.
- No verified secure update mechanism.
- No complete malware protection.
- No established protection against malicious applications.
- No guarantee against exploits, vulnerabilities or unauthorized access.

Important warnings

- Do not store passwords, personal information or sensitive files on rewindOS.
- Do not use it for banking, payments or other sensitive activities.
- Do not install applications from untrusted sources.
- Do not assume downloaded applications are safe.
- Test rewindOS in a virtual machine whenever possible.
- Use disposable virtual disks and avoid connecting experimental builds to sensitive networks.
